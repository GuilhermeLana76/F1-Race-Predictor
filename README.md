# 🏎️ F1 Race Predictor

A web application for predicting Formula 1 race results.

The project is being developed as a study project to practice **frontend, backend, APIs, databases, and AI integration**.

## 🚀 Technologies

* HTML5
* CSS3
* JavaScript
* Python
* Flask
* SQLite
* Jolpica-F1 API
* AI API

## 🎯 Project Goal

The goal is to allow users to make predictions for Formula 1 races and compare their predictions with the real race results.

## 📌 Status

🚧 **In development**

More features will be added throughout the development of the project.
